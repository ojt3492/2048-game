# 2048

브라우저에서 바로 즐길 수 있는 2048 퍼즐 게임입니다. 빌드나 설치 과정 없이 `index.html` 파일 하나로 동작합니다.

## 플레이 방법

`index.html`을 브라우저에서 열면 바로 시작할 수 있습니다.

- **방향키** 또는 **WASD**로 타일을 이동합니다.
- 모바일/터치 화면에서는 **스와이프**로 이동할 수 있습니다.
- 같은 숫자의 타일 두 개가 만나면 하나로 합쳐지며 점수가 올라갑니다.
- 2048 타일을 만들면 승리하며, 이후에도 "계속하기"로 더 큰 타일에 도전할 수 있습니다.
- 최고 점수는 브라우저의 `localStorage`에 저장되어 다음 방문에도 유지됩니다.

## 로컬에서 실행하기

별도 설치가 필요 없습니다. 저장소를 클론한 뒤 `index.html`을 브라우저로 열기만 하면 됩니다.

```bash
git clone https://github.com/ojt3492/2048-game.git
cd 2048-game
```

이후 `index.html`을 더블 클릭하거나 브라우저 드래그 앤 드롭으로 열어주세요.

## 기술 스택

순수 HTML, CSS, JavaScript(바닐라)로만 작성되었으며 외부 라이브러리나 빌드 도구를 사용하지 않습니다.
